## Simple Calculator built with React Project
## Aim

To design and develop a simple calculator using React that performs basic arithmetic operations such as addition, subtraction, multiplication, and division through an interactive web interface.

## Algorithm
Start the React application.
Create the calculator interface using React components.
Display a screen to show the entered numbers and calculated result.
Create buttons for digits (0–9) and arithmetic operators (+, −, ×, ÷).
Accept the user's input through button clicks.
Store and update the input using React state.
Perform the selected arithmetic operation when the = button is pressed.
Display the calculated result on the calculator screen.
Provide a Clear button to reset the calculator.
Stop.
